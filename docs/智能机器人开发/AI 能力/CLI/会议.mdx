会议服务，提供会议的创建、查询、搜索、取消、更新等能力。

> 使用前需在机器人管理后台授权「**会议**」能力权限，授权方式参考[开发前必读 — 能力授权](#62131/能力授权)。

## 命令说明

| 命令 | 说明 |
|---|---|
| `wecom-cli meeting cancel` | 取消预定会议：周期会议取消单次需指定子会议 ID |
| `wecom-cli meeting create` | 创建会议 |
| `wecom-cli meeting get` | 获取会议详情：标题、开始时间、结束时间、是否全天、时区、会议室、周期规则、参与人列表、会议状态、智能纪要地址、录制文件地址、地点、备注 |
| `wecom-cli meeting list` | 按时间范围拉取开始时间在对应范围内的会议列表：标题、开始时间、结束时间、参会人数量、时区、会议室、地点、是否是周期会议 |
| `wecom-cli meeting search` | 按关键词搜索会议：支持按关键词匹配会议主题，可选按时间范围过滤，支持 cursor 分页和上翻下翻方向控制。 |
| `wecom-cli meeting update` | 更新预定会议信息：标题、开始时间、结束时间、参与人、地点、备注 |
| `wecom-cli meeting original get` | 拉取会议转写原文。 |
| `wecom-cli meeting rooms search` | 查询会议室。 |
| `wecom-cli meeting rooms buildings list` | 查询企业会议室楼栋信息。 |
