智能文档服务，提供页面读取、创建、删除、重命名、移动、布局更新、Block 编辑及内容追加与覆盖等能力。

> 使用前需在机器人管理后台授权「**文档**」能力权限，授权方式参考[开发前必读 — 能力授权](#62131/能力授权)。

## 命令说明

| 命令 | 说明 |
|---|---|
| `wecom-cli smartpage create` | 新建智能文档 |
| `wecom-cli smartpage import` | 导入 markdown 创建智能文档 |
| `wecom-cli smartpage blocks update` | 编辑智能文档block(插入/替换/删除) |
| `wecom-cli smartpage databases get` | 读取数据库信息 |
| `wecom-cli smartpage files upload` | 上传文件到文档,得到url |
| `wecom-cli smartpage images upload` | 上传图片到文档,得到url |
| `wecom-cli smartpage pages append` | 追加内容到页面 |
| `wecom-cli smartpage pages get` | 读取智能文档内容 |
| `wecom-cli smartpage pages overwrite` | 覆盖页面内容 |
| `wecom-cli smartpage pages update` | 修改页面(创建/删除/重命名/移动/更新布局) |
