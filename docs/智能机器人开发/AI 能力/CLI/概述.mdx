## 概述

CLI（`wecom-cli`）是企业微信提供的命令行工具，支持对文档、日程、会议、待办等企业数据进行读写操作。用户、AI Agent 及自动化脚本均可通过 CLI 命令与企业微信数据直接交互。详见 [GitHub 仓库](https://github.com/WecomTeam/wecom-cli)。

---

## 安装

```bash
npm install -g @wecom/cli
```

---

## 初始化

```bash
wecom-cli auth init
```

执行后会进入交互式向导，选择接入方式：

- **扫码接入（推荐）**：用企业微信客户端扫描终端二维码，自动创建并绑定一个新机器人，无需额外操作
- **手动输入 Bot ID 和 Secret**：手动输入已有机器人的 `bot_id` 和 `websocket_secret`

---

## Skill

为 LLM（Claude / Cursor 等）安装CLI Skill 后，LLM 可以直接理解并调用 CLI 命令完成数据操作，无需手动组织命令。

```bash
npx skills add WeComTeam/wecom-cli -y -g
```

## OpenClaw 接入

安装 OpenClaw 插件后，可在 OpenClaw 环境中直接使用 `wecom-cli` 对企业微信数据进行读写操作，无需额外配置。
