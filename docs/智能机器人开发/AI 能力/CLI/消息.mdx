消息服务，提供消息发送等能力。

> 使用前需在机器人管理后台授权「**消息**」能力权限，授权方式参考[开发前必读 — 能力授权](#62131/能力授权)。

## 命令说明

| 命令 | 说明 |
|---|---|
| `wecom-cli message aibot send` | 以智能机器人身份向指定单聊/群聊会话发送消息，支持 markdown/图片/文件/语音/视频 |
| `wecom-cli message aibot sessions list` | 获取智能机器人最近的会话列表，按最后一条消息时间倒序返回最多 20 个会话 |
