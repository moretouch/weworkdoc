## 概述

授权会议权限后，机器人可代替成员访问企业微信会议，实现会议的创建、查询、更新、取消等操作。

**支持的能力：**

- 创建会议
- 查询会议详情
- 按时间范围拉取会议列表
- 按关键词搜索会议
- 更新会议信息（标题、时间、参与人、地点等）
- 取消会议
- 查询会议室
- 查询企业会议室楼栋信息
- 拉取会议转写原文

## 授权流程

在机器人管理后台进入机器人编辑页，点击「可使用权限」，选择「会议」能力授权。

## 工具说明

| 工具 | 说明 |
|---|---|
| `meeting_cancel` | 取消预定会议：周期会议取消单次需指定子会议 ID |
| `meeting_create` | 创建会议 |
| `meeting_get` | 获取会议详情：标题、开始时间、结束时间、是否全天、时区、会议室、周期规则、参与人列表、会议状态、智能纪要地址、录制文件地址、地点、备注 |
| `meeting_list` | 按时间范围拉取开始时间在对应范围内的会议列表：标题、开始时间、结束时间、参会人数量、时区、会议室、地点、是否是周期会议 |
| `meeting_search` | 按关键词搜索会议：支持按关键词匹配会议主题，可选按时间范围过滤，支持 cursor 分页和上翻下翻方向控制。 |
| `meeting_update` | 更新预定会议信息：标题、开始时间、结束时间、参与人、地点、备注 |
| `meeting_original_get` | 拉取会议转写原文。 |
| `meeting_rooms_search` | 查询会议室。 |
| `meeting_rooms_buildings_list` | 查询企业会议室楼栋信息。 |
| `calendar_schedules_free_list` | 查询指定成员在指定时间范围内的共同空闲时段，返回推荐的空闲时间段列表 |
