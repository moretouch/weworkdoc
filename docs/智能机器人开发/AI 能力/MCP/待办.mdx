## 概述

授权待办权限后，机器人可代替成员管理企业微信待办，实现待办的创建、查询、更新、删除、完成等操作。

**支持的能力：**

- 创建待办
- 查询待办详情
- 读取待办列表（支持关键词、状态、时间过滤）
- 更新待办（标题、描述、参与人、截止时间等）
- 删除待办
- 完成待办

## 授权流程

在机器人管理后台进入机器人编辑页，点击「可使用权限」，选择「待办」能力授权。

## 工具说明

| 工具 | 说明 |
|---|---|
| `todo_create` | 机器人创建待办，支持设置标题、描述、截止时间、参与人等信息 |
| `todo_get` | 批量读取待办详情，返回标题、描述、状态、截止时间、参与人等信息 |
| `todo_list` | 读取待办列表，支持按关键词、状态、时间范围过滤，支持分页 |
| `todo_update` | 机器人更新待办信息，支持修改标题、描述、截止时间、参与人等字段 |
| `todo_delete` | 机器人删除待办 |
| `todo_finish` | 机器人完成待办 |
