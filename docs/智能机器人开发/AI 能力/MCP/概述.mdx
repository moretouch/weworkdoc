## 概述

智能机器人默认仅支持消息收发。通过授权「可使用权限」，机器人可以访问企业微信中的其他数据，例如代替成员新建文档、读取会议信息、管理待办等。

各能力权限需成员**单独授权**，授权后机器人通过授权链接接入自有系统（支持 MCP 协议和普通 HTTP 请求两种方式）。

---

## 授权流程

1. 进入：工作台 → 智能机器人 → 找到对应 API 模式机器人 → 进入详情页面
2. 在详情页页，点击「可使用权限」的查看
![enter image description here](https://wework.qpic.cn/wwpic3az/684909_81qRmXxbRbSqKU9_1786950710/0)

3. 选择需要授权的能力，点击「授权」

![enter image description here](https://wework.qpic.cn/wwpic3az/947721_3jhx3DyRR16hcNw_1786950770/0)

4. 授权成功，点击「查看使用方式」
![enter image description here](https://wework.qpic.cn/wwpic3az/92070_B6rAn0vER7yO23d_1786950874/0)

5. 复制 streamableHTTP URL或JSON Config，按需选择接入方式

![enter image description here](https://wework.qpic.cn/wwpic3az/890516_8H0Ca2b6S7eO56G_1786950892/0)

> **注意**：当前文档权限有效期为 **7 天**，到期需重新授权。请妥善保管授权链接，切勿泄露。

若需在OpenClaw 中使用，参考：[以长连接方式接入 OpenClaw](https://open.work.weixin.qq.com/help2/pc/cat?doc_id=21658)
