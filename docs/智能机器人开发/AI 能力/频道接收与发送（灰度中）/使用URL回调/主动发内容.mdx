机器人可在没有被@的情况下，主动向频道推送内容。仅支持频道的机器人调用。


## 发送帖子
**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/aibot/topic/send_post?access_token=ACCESS_TOKEN
```
{
	"topic_id": "TOPIC_ID",
	"content": "带占位符的 markdown 内容",
	"inline_file_list": [
		{
			"placeholder": "PLACE_HOLDER",
			"media_id": "MEDIA_ID"
		}
	],
	"inline_mention_list": [
		{
			"placeholder": "PLACE_HOLDER",
			"member": {
				"type": 0,
				"userid": "USERID"
			}
		}
	],
	"image_list": [
		{
			"media_id": "MEDIA_ID"
		}
	],
	"feedback": {
		"id": "FEEDBACK_ID"
	}
}
```

**参数说明：** 

| 参数      | 是否必须| 类型| 说明   |
| ------- | ---- | --|-- |
|access_token|是|String|机器人调用接口凭证|
|topic_id|是|String|频道ID，长度不超过 128 字节|
|content|是|String|markdown格式内容，可内嵌文件/@人，详见[占位符说明](#content_note)。长度不超过 20480 字节|
|inline_file_list|否|object[]|content内嵌文件列表，不超过8个|
|inline_file_list[].placeholder|是|string| content 中 ${inline_file:placeholder}  对应的 placeholder；仅支持大小写字母、数字、下划线(_)、横杆(-)，长度 1~32 字符|
|inline_file_list[].media_id|是|string| 临时素材ID，仅支持`file`类型，可通过[上传临时素材](#62615)获取；长度不超过 128 字节|
|inline_mention_list|否|object[]|content内嵌@人列表，不超过8个|
|inline_mention_list[].placeholder|是|string| content 中 ${inline_mention:placeholder} 对应的 placeholder；仅支持大小写字母、数字、下划线(_)、横杆(-)，长度 1~32 字符  |
|inline_mention_list[].member|是|Object([UserInfo](#UserInfo))| 被 @ 的成员信息，仅支持 `type=0`（成员），不支持 @ 机器人 |
| image_list | 否 | object[] | 图片列表，不超过8个 |
| image_list[].media_id | 是 | string | 临时素材ID，仅支持`image`类型，可通过[上传临时素材](#62615)获取；长度不超过 128 字节 |
| feedback | 否 | Object | 反馈配置 |
| feedback.id | 否 | String | 不为空时，用户反馈会触发[用户反馈事件](#62610)，不超过 256 字节 |

**返回结果：**
```json
{
	"errcode": 0,
	"errmsg": "ok",
	"post_id": "POST_ID"
}
```
**参数说明：**

| 参数      | 类型|说明   |
| ------- | --|-- |
|errcode |Integer|错误码  |
|errmsg|String|错误码说明|
|post_id |String|帖子ID  |

### content 占位符说明
假如 content 内容如下：

``` markdown
${inline_mention_all} 这是活动方案：${inline_file:placeholder_A}，请${inline_mention:placeholder_B} 特别关注。
```

请求 json 补充关于 placeholder 的说明：

``` 
{
	"inline_file_list": [
		{
			"placeholder": "placeholder_A",
			"media_id": "MEDIA_ID"
		}
	],
	"inline_mention_list": [
		{
			"placeholder": "placeholder_B",
			"member": {
				"type": 0,
				"userid": "USERID"
			}
		}
	]
}
```

<span></span>
::: tip 说明
`${inline_mention_all}`会被渲染为 @所有人
`${inline_mention:placeholder_A}`会被渲染为 @某个成员
`${inline_file:placeholder_A}`会被渲染为 可点击预览的文件超链接
如果是获取帖子/评论/回复详情，`inline_file_list`获取到的结构中，不是`media_id`，而是`download_url`。
:::


### UserInfo

| 参数 | 类型 | 说明 |
|------|------|------|
| type | Integer | 用户类型：0-成员 `userid`，1-机器人 `aibotid` |
| userid | String | 成员 userid，`type` 为 0 时有值，长度不超过 64 字节 |
| aibotid | String | 机器人 botid，`type` 为 1 时有值，长度不超过 64 字节 |
