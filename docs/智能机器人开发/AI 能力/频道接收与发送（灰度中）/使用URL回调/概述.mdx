## 概述

URL 回调方式（Webhook）是智能机器人 API 模式的一种连接方式。开启后，当用户与机器人交互时，企业微信会将频道内容和事件**主动推送**到开发者预先配置的回调 URL，开发者可进一步主动调用相关接口（需要先[获取调用凭证](#62616)）获取内容、回复内容。

与长连接方式相比，URL 回调方式的主要特点：

- **支持负载均衡**：回调可分发至多个服务实例，适合对高可用有要求的场景
- **无需维护连接**：每次回调独立建连，无需心跳保活和断线重连逻辑
- **需要公网地址**：回调 URL 必须公网可访问，内网环境需配置公网映射

两种方式详细对比参考[开发前必读 — 连接方式对比](#62131/连接方式对比)。

> 接收消息需加密，加密方式参考[加解密方案](#62162)。请妥善保管 URL、Token、Encoding-AESKey，切勿泄露。

## 配置回调地址

在管理后台开启 API 模式，选择「URL 回调」方式后，填写以下信息：

| 配置项 | 说明 |
|---|---|
| URL | 开发者服务的回调地址，必须**公网可访问**，支持 HTTP 和 HTTPS |
| Token | 用于生成签名，校验回调来源合法性 |
| Encoding-AESKey | 消息体加解密密钥，长度固定为 43 个字符 |

![创建智能机器人 API 模式 — URL 回调方式](https://wework.qpic.cn/wwpic3az/899657_S8HSuIb8RFW-OvR_1786716598/0)

点击「保存」时，企业微信会向填写的 URL 发送一条验证请求，开发者需正确响应才能通过验证。验证方式详见[加解密方案 — 验证 URL 有效性](#62162/验证-url-有效性)。
