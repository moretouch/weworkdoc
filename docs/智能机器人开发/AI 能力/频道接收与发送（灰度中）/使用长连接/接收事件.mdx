## 概述

当用户在频道中与智能机器人发生交互，或频道、帖子、回复发生变更时，企业微信会通过长连接推送事件回调（`aibot_topic_event_callback`）。

支持的事件类型：

- [频道内被 @ 事件](#频道内被-事件)：用户在帖子或回复中 @ 机器人
- [机器人加入/移除频道事件](#机器人加入移除频道事件)：机器人被加入或移出频道
- [频道成员变更事件](#频道成员变更事件)：频道成员加入或被移除
- [频道信息变更事件](#频道信息变更事件)：频道名称、描述、权限或创建者发生变更
- [帖子变更事件](#帖子变更事件)：帖子新建、更新或删除
- [回复变更事件](#回复变更事件)：回复新建、更新或删除
- [用户反馈事件](#用户反馈事件)：用户对机器人生成的帖子或回复进行点赞、点踩等反馈

## 通用字段说明

所有频道事件回调均包含以下通用字段：

```json
{
    "cmd": "aibot_topic_event_callback",
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "msgid": "CAIQ16HMjQYY/NGagIOAgAMgq4KM0AI=",
        "create_time": 1700000000,
        "aibotid": "AIBOTID",
        "topic_id": "TOPICID",
        "from": {
            "userid": "USERID"
        },
        "msgtype": "event",
        "event": {
            "eventtype": "eventtype_name",
            "eventtype_name": {}
        }
    }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| cmd | string | 固定值 `aibot_topic_event_callback` |
| headers.req_id | string | 请求唯一标识 |
| body.msgid | string | 本次回调的唯一标识，开发者需据此进行事件排重 |
| body.create_time | int | 回调事件产生的时间，Unix 时间戳，单位为秒。帖子和回复事件不额外提供独立的变更时间字段 |
| body.aibotid | string | 智能机器人 ID |
| body.topic_id | string | 频道 ID，统一放在回调外层 |
| body.from.userid | string | 操作者或事件发起者的 userid。from 结构体中，aibotid 和 userid 互斥 |
| body.from.aibotid | string | 操作者或事件发起机器人的 aibotid。from 结构体中，aibotid 和 userid 互斥 |
| body.msgtype | string | 消息类型，事件通知固定为 `event` |
| body.event.eventtype | string | 事件类型名称 |
| body.event.eventtype_name | object | 与 `eventtype` 同名的具体事件结构体 |

### 频道 ID 字段说明

| 字段 | 说明 |
|---|---|
| `topic_id` | 频道 ID |
| `post_id` | 频道中的帖子 ID |
| `reply_id` | 帖子下的回复 ID |
| `from.userid` | 操作人、作者或反馈用户的 userid，具体含义取决于事件类型 |

## 事件格式

## 频道内被 @ 事件

当用户在频道帖子或回复中 @ 机器人时触发。机器人收到事件后，可通过频道接口获取被 @ 所在帖子的完整上下文，包括帖子、回复、附件和表情等内容。

```json
{
    "cmd": "aibot_topic_event_callback",
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "msgid": "CAIQ16HMjQYY/NGagIOAgAMgq4KM0AI=",
        "create_time": 1700000000,
        "aibotid": "AIBOTID",
        "topic_id": "TOPICID",
        "from": {
            "userid": "USERID"
        },
        "msgtype": "event",
        "event": {
            "eventtype": "topic_at_bot",
            "topic_at_bot": {
                "post_id": "POSTID",
                "reply_id": "REPLYID"
            }
        }
    }
}
```

参数说明：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| `body.event.eventtype` | 是 | 固定为 `topic_at_bot` |
| `body.event.topic_at_bot.post_id` | 是 | 被 @ 所在的帖子 ID |
| `body.event.topic_at_bot.reply_id` | 否 | 被 @ 所在的回复 ID。在帖子正文中直接 @ 时不返回该字段 |
| `body.from.userid` | 是 | @ 机器人的用户 userid |

## 机器人加入/移除频道事件

当机器人被加入频道或从频道中移除时触发。

```json
{
    "cmd": "aibot_topic_event_callback",
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "msgid": "CAIQ16HMjQYY/NGagIOAgAMgq4KM0AI=",
        "create_time": 1700000000,
        "aibotid": "AIBOTID",
        "topic_id": "TOPICID",
        "from": {
            "userid": "USERID"
        },
        "msgtype": "event",
        "event": {
            "eventtype": "topic_bot_join_leave",
            "topic_bot_join_leave": {
                "change_type": 1
            }
        }
    }
}
```

参数说明：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| `body.event.eventtype` | 是 | 固定为 `topic_bot_join_leave` |
| `body.event.topic_bot_join_leave.change_type` | 是 | 变化类型：`1` 被加入，`2` 被移除 |
| `body.from.userid` | 是 | 执行加入或移除操作的用户 userid |

## 频道信息变更事件

当频道的基本信息发生变更时触发。支持权限、名称、描述和创建者变更。

```json
{
    "cmd": "aibot_topic_event_callback",
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "msgid": "CAIQ16HMjQYY/NGagIOAgAMgq4KM0AI=",
        "create_time": 1700000000,
        "aibotid": "AIBOTID",
        "topic_id": "TOPICID",
        "from": {
            "userid": "OPERATOR_USERID"
        },
        "msgtype": "event",
        "event": {
            "eventtype": "topic_info_change",
            "topic_info_change": {
                "info_type": 2
            }
        }
    }
}
```

参数说明：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| `body.event.eventtype` | 是 | 固定为 `topic_info_change` |
| `body.event.topic_info_change.info_type` | 是 | 信息变化类型，见下表 |
| `body.from.userid` | 是 | 执行信息变更操作的用户 userid |

`info_type` 取值：

| 值 | 含义 |
|---|---|
| `1` | 权限变更，公开/私有状态发生变化 |
| `2` | 名称变更 |
| `3` | 描述变更 |
| `4` | 创建者变更 |

## 帖子变更事件

当频道中的帖子新建、更新或删除时触发。

```json
{
    "cmd": "aibot_topic_event_callback",
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "msgid": "CAIQ16HMjQYY/NGagIOAgAMgq4KM0AI=",
        "create_time": 1700000000,
        "aibotid": "AIBOTID",
        "topic_id": "TOPICID",
        "from": {
            "userid": "AUTHOR_USERID"
        },
        "msgtype": "event",
        "event": {
            "eventtype": "topic_event",
            "topic_event": {
                "type": 1,
                "post_id": "POSTID"
            }
        }
    }
}
```

参数说明：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| `body.event.eventtype` | 是 | 固定为 `topic_event` |
| `body.event.topic_event.type` | 是 | 变更类型：`1` 新建，`2` 更新，`3` 删除 |
| `body.event.topic_event.post_id` | 是 | 发生变更的帖子 ID |
| `body.from.userid` | 是 | 帖子作者，也是该事件的操作者 |

> 帖子变更事件不携带帖子内容摘要，也不额外返回独立的变更时间。需要获取帖子内容时，开发者应根据 `topic_id` 和 `post_id` 调用频道内容接口。

## 用户反馈事件

当用户对机器人在频道中生成的帖子或回复进行点赞、点踩或取消反馈时触发。

```json
{
    "cmd": "aibot_topic_event_callback",
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "msgid": "CAIQ16HMjQYY/NGagIOAgAMgq4KM0AI=",
        "create_time": 1700000000,
        "aibotid": "AIBOTID",
        "topic_id": "TOPICID",
        "from": {
            "userid": "FEEDBACK_USERID"
        },
        "msgtype": "event",
        "event": {
            "eventtype": "feedback_event",
            "feedback_event": {
                "type": 2,
                "id": "FEEDBACKID",
                "content": "能再详细一些么",
                "inaccurate_reason_list": [2, 4],
                "post_id": "POSTID",
                "reply_id": "REPLYID"
            }
        }
    }
}
```

参数说明：

| 参数 | 是否必填 | 说明 |
|---|---|---|
| `body.event.eventtype` | 是 | 固定为 `feedback_event` |
| `body.event.feedback_event.type` | 是 | 反馈类型：`1` 准确，`2` 不准确，`3` 取消准确或不准确 |
| `body.event.feedback_event.id` | 是 | 回复消息中设置的反馈 id |
| `body.event.feedback_event.content` | 否 | 用户输入的反馈内容，仅不准确反馈类型返回 |
| `body.event.feedback_event.inaccurate_reason_list` | 否 | 用户选择的负反馈原因列表，仅不准确反馈类型返回 |
| `body.event.feedback_event.post_id` | 是 | 反馈对象所属的帖子 ID |
| `body.event.feedback_event.reply_id` | 否 | 反馈对象为回复时返回，帖子反馈不返回 |
| `body.from.userid` | 是 | 提交反馈的用户 userid |

负反馈原因取值：

| 值 | 含义 |
|---|---|
| `1` | 与内容无关 |
| `2` | 内容不完整 |
| `3` | 内容有错误 |
| `4` | 数据分析错误 |

## 回调处理建议

1. 使用 `body.msgid` 对所有事件进行幂等排重。
2. 帖子和回复事件中的 `body.from.userid` 同时表示作者和操作者。
3. `feedback_event` 中根据反馈对象类型判断是否存在 `reply_id`；不存在时表示反馈对象是帖子。
4. 与 URL 回调收到的事件结构一致（URL 回调的结构体 = 长连接的 `body` 部分），差异仅在传输通道：
   - URL 回调：加密后 POST 到机器人配置的接收消息 URL
   - 长连接：通过 WebSocket 推送，`cmd` 为 `aibot_topic_event_callback`，`body` 中携带事件内容
