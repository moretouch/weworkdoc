机器人可以获取频道下的内容，可全量拉取或指定拉取。仅支持频道的机器人调用。

## 获取帖子列表和内容
获取指定频道下的帖子，可按顺序全量拉取，或指定帖子ID拉取。

**请求示例：**
```json
{
	"cmd": "aibot_topic_get_post_list",
	"headers": {
		"req_id": "REQUEST_ID"
	},
	"body": {
		"topic_id": "TOPIC_ID",
		"type": 0,
		"post_id_list": [
			"POST_ID"
		],
		"begin_time": 1700000000,
		"end_time": 1700100000,
		"sort_type": 0,
		"cursor": "CURSOR",
		"limit": 10
	}
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| cmd | string | 是 | 固定值 `aibot_topic_get_post_list` |
| headers.req_id | string | 是 | 请求唯一标识，由开发者自行生成 |
| body.topic_id | string | 是 | 频道ID，长度不超过 128 字节 |
| body.type | integer | 否 | 获取类型：0-指定`post_id_list`获取（默认）；1-分页获取话题下的所有帖子；|
| body.post_id_list | string[] | 否 | 指定获取的帖子ID列表，不超过 50 个，单个ID长度不超过 128 字节`type`为 0 时有效|
| body.begin_time | integer | 否 | 起始时间（秒级时间戳），`type`为 1 时有效 |
| body.end_time | integer | 否 | 结束时间（秒级时间戳），`type`为 1 时有效 |
| body.sort_type | integer | 否 | 排序方式。0-按帖子创建时间从旧到新（默认），1-从新到旧。`type`为 1 时有效。翻页过程中 sort_type 须保持一致|
| body.cursor | string | 否 | 分页游标，首页为空，长度不超过 256 字节，`type`为 1 时有效|
| body.limit | integer | 否 | 分页大小，默认 20，最大 50，`type`为 1 时有效|

### content 占位符说明
假如 content 内容如下：

``` markdown
${inline_mention_all} 这是活动方案：${inline_file:placeholder_A}，请${inline_mention:placeholder_B} 特别关注。

讨论记录见：${inline_chat_record:placeholder_C}
```

返回的 json 同时附带关于 placeholder 的说明：

``` 
{
	"inline_file_list": [
		{
			"placeholder": "placeholder_A",
			"download_url": "MEDIA_ID",
			"cookie_name": "cookie名字，下载需要设置",
			"cookie_value": "cookie值，下载需要设置"
		}
	],
	"inline_mention_list": [
		{
			"placeholder": "placeholder_B",
			"member": {
				"type": 0,
				"userid": "USERID"
			}
		}
	],
	"inline_chat_record_list": [
		{
			"placeholder": "placeholder_C",
			"chat_record_id": "CHAT_RECORD_ID"
		}
	]
}
```

<span></span>
:::: tip 说明
`${inline_mention_all}` - 客户端渲染为 @所有人
`${inline_mention:placeholder_A}` - 客户端渲染为 @某个成员
`${inline_file:placeholder_A}` - 客户端渲染为 可点击预览的文件超链接
`${inline_chat_record:placeholder_C}` - 客户端渲染为 可展开的聊天记录卡片
`inline_file_list` 获取到的结构中，为下载链接`download_url`以及附带的cookie信息。
`inline_chat_record_list` 获取到的结构中，`chat_record_id` 可传给 `get_chat_record` 接口获取聊天记录详情。
::::

### UserInfo

| 参数 | 类型 | 说明 |
|------|------|------|
| type | Integer | 用户类型：0-成员 `userid`，1-机器人 `aibotid` |
| userid | String | 成员 userid，`type` 为 0 时有值，长度不超过 64 字节 |
| aibotid | String | 机器人 botid，`type` 为 1 时有值，长度不超过 64 字节 |

### PostInfo
| 参数      | 类型|说明   |
| ------- | --|-- |

|image_list[].cookie_name|string| 下载请求带cookie的key |
