机器人收到被 @ 回调事件后，允许调用接口获取指定的帖子和回复内容。（超过24小时则不可调用）。

## 获取指定的帖子列表和内容
获取指定频道下的帖子，可指定帖子ID拉取。

**请求示例：**
```json
{
	"cmd": "aibot_topic_get_post_list",
	"headers": {
		"req_id": "REQUEST_ID"
	},
	"body": {
		"topic_id": "TOPIC_ID",
		"post_id_list": [
			"POST_ID"
		]
	}
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| cmd | string | 是 | 固定值 `aibot_topic_get_post_list` |
| headers.req_id | string | 是 | 请求唯一标识，由开发者自行生成 |
| body.topic_id | string | 是 | 频道ID，长度不超过 128 字节 |
| body.post_id_list | string[] | 否 | 指定获取的帖子ID列表，不超过 50 个，单个ID长度不超过 128 字节 |
<!--| body.begin_time | integer | 否 | 起始时间（秒级时间戳），`type`为 1 时有效 |
| body.end_time | integer | 否 | 结束时间（秒级时间戳），`type`为 1 时有效 |
| body.sort_type | integer | 否 | 排序方式。0-按帖子创建时间从旧到新（默认），1-从新到旧。`type`为 1 时有效。翻页过程中 sort_type 须保持一致 |
| body.cursor | string | 否 | 分页游标，首页为空，长度不超过 256 字节，`type`为 1 时有效 |
| body.limit | integer | 否 | 分页大小，默认 20，最大 50，`type`为 1 时有效 |
| body.type | integer | 是 | 获取类型：0-指定`post_id_list`获取；1-分页获取频道下的所有帖子 | -->

## 获取指定的评论列表和内容
获取指定频道和帖子下的评论/回复，可指定评论ID拉取。

**请求示例：**
```json
{
	"cmd": "aibot_topic_get_reply_list",
	"headers": {
		"req_id": "REQUEST_ID"
	},
	"body": {
		"topic_id": "TOPIC_ID",
		"post_id": "POST_ID",
		"reply_id_list": [
			"REPLY_ID"
		]
	}
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| cmd | string | 是 | 固定值 `aibot_topic_get_reply_list` |
| headers.req_id | string | 是 | 请求唯一标识，由开发者自行生成 |
| body.topic_id | string | 是 | 频道ID，长度不超过 128 字节 |
| body.post_id | string | 是 | 帖子ID，长度不超过 128 字节 |
| body.reply_id_list | string[] | 否 | 指定获取的评论ID列表，不超过 50 个，单个ID长度不超过 128 字节 |
<!-- | body.type | integer | 是 | 获取类型：0-指定`reply_id_list`获取；1-分页获取帖子下的所有评论 |
