## 获取频道列表
机器人可以获取机器人所在的频道列表，可指定频道ID拉取，或分页遍历机器人已加入的所有频道。仅支持频道的机器人调用。

**请求示例：**
```json
{
	"cmd": "aibot_topic_get_topic_list",
	"headers": {
		"req_id": "REQUEST_ID"
	},
	"body": {
		"type": 0,
		"topic_id_list": [
			"TOPIC_ID"
		],
		"cursor": "CURSOR",
		"limit": 20
	}
}
```

**请求字段说明：** 

| 字段      | 类型| 必填| 说明   |
| ------- | ---- | --|-- |
| cmd | string | 是 | 固定值 `aibot_topic_get_topic_list` |
| headers.req_id | string | 是 | 请求唯一标识，由开发者自行生成 |
| body.type|否|Interger|获取类型：0-指定`topic_id_list`获取（默认）；1-分页获取机器人已加入的所有频道|
| body.topic_id_list|否|String[]|指定获取的频道ID列表，不超过100个，单个 ID 长度不超过 128 字节，`type`为 0 时有效。需为机器人已加入的频道，未加入的频道ID将被跳过|
| body.cursor|否|String|分页游标，首页为空，长度不超过 256 字节，`type`为 1 时有效|
| body.limit|否|Interger|分页大小，默认20，最大100，`type`为 1 时有效|

**响应示例：**
```json
{
	"headers": {
		"req_id": "REQUEST_ID"
	},
	"body": {
		"topic_list": [
			{
				"topic_id": "TOPIC_ID",
				"topic_name": "TOPIC_NAME",
				"topic_desc": "TOPIC_DESC",
				"permission": 0,
				"creator": {
					"type": 0,
					"userid": "USER_ID"
				},
				"create_time": 1758518400
			}
		],
		"has_more": true,
		"next_cursor": "NEXT_CURSOR"
	},
	"errcode": 0,
	"errmsg": "ok"
}
```
**参数说明：**

| 参数      | 类型|说明   |
| ------- | --|-- |
|errcode |Integer|错误码  |
|errmsg|String|错误码说明|
|body.topic_list| Object([TopicInfo](#TopicInfo))[]| 频道详情列表 |
|body.has_more|Bool|是否有更多数据，`type`为 1 时有效|
|body.next_cursor|String|下一页的游标，`type`为 1 时有效|

## 获取频道成员列表

获取指定频道的成员列表，包含普通成员和机器人。

**请求示例：**
```json
{
    "cmd": "aibot_topic_get_topic_member_list",
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "topic_id": "TOPIC_ID",
        "cursor": "CURSOR",
        "limit": 100
    }
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| cmd | string | 是 | 固定值 `aibot_topic_get_topic_member_list` |
| headers.req_id | string | 是 | 请求唯一标识，由开发者自行生成 |
| body.topic_id | string | 是 | 频道 ID，长度不超过 128 字节 |
| body.cursor | string | 否 | 分页游标，首页为空，长度不超过 256 字节 |
| body.limit | integer | 否 | 分页大小，默认 100，最大 200 |

**响应示例：**

```json
{
    "headers": {
        "req_id": "REQUEST_ID"
    },
    "body": {
        "member_list": [
            {
                "type": 0,
                "userid": "USER_ID"
            },
            {
                "type": 1,
                "aibotid": "BOT_ID"
            }
        ],
        "has_more": true,
        "next_cursor": "NEXT_CURSOR"
    },
    "errcode": 0,
    "errmsg": "ok"
}
```

**参数说明：**

| 参数 | 类型 | 说明 |
|------|------|------|
| errcode | Integer | 错误码 |
| errmsg | String | 错误码说明 |
| body.member_list | Object([UserInfo](#63045/UserInfo))[]| 成员列表 |
| body.has_more | Bool | 是否有更多数据 |
| body.next_cursor | String | 下一页的游标 |
