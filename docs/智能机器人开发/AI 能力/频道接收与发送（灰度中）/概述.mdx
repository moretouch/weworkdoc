## 概述
频道，由「邮件-话题」功能升级而来，并支持添加智能机器人到频道中，此功能在 5.0.12 推出并正在灰度中。在灰度期间，原有的「邮件-话题」亦可添加智能机器人，同时使用部分开放能力，在下文会具体说明。

智能机器人开启 API 模式后，企业微信会将用户在频道（灰度中）中发送的内容和触发的事件，通过回调推送给开发者的服务。开发者处理完业务逻辑后，可以回复内容或主动向用户推送内容。

## 连接方式

API 模式支持两种连接方式，两者**互斥**，同一时间只能启用其中一种：

| 连接方式 | 适用场景 | 详细文档 |
|---|---|---|
| 长连接`(开发中）` | 内网部署、对实时性要求高、需要主动推送内容 | [使用长连接](#62154) |
| URL 回调 | 服务器有公网 IP、对高可用有要求（支持多实例负载均衡） | [使用 URL 回调](#62807) |

> 切换连接方式后，原有的回调地址或长连接将立即失效。

### 连接方式对比

| 特性 | 长连接 | URL 回调 |
|---|---|---|
| 服务端要求 | 无需固定公网 IP | 需要公网可访问的回调 URL |
| 内容加解密 | 无需，明文传输 | 需要 |
| 流式内容 | 开发者主动推送，无需等待轮询 | 企业微信轮询回调获取最新内容 |
| 素材上传 | 支持（[上传临时素材](#62159)） | 支持（[上传临时素材](#62615)） |
| 高可用 | 同一时间仅允许一个有效连接 | 支持多实例负载均衡 |
| 开发复杂度 | 低（官方 SDK 内置心跳与断线重连） | 低 |

## 「话题」支持的能力范围
频道由「邮件 - 话题」演进而来，在频道功能灰度期间，话题亦可使用部分能力并已开放，包含：
- [话题内被 @ 事件](https://developer.work.weixin.qq.com/document/62610) ：用户在帖子或回复中 @ 机器人
- [用户反馈事件](https://developer.work.weixin.qq.com/document/62610) ：用户对机器人生成的帖子或回复进行点赞、点踩等反馈
- [获取被@的内容](https://developer.work.weixin.qq.com/document/62733) ：机器人收到被 @ 回调事件后，允许调用接口获取帖子和回复内容。
- [回复被@的内容](https://developer.work.weixin.qq.com/document/62734) ：机器人收到被 @ 回调事件后， 允许调用接口回复、贴表情。

## 与「群聊通道」的兼容处理
- 为保证已有机器人的使用体验，机器人加入频道后，频道内容会通过「群聊通道」同步给已适配群聊的机器人，回复也会同步回频道。
-  建议适配频道接口，机器人可以理解结构化内容，获取频道全部内容和信息。
-  适配后需[停止"群聊通道"的同步](https://developer.work.weixin.qq.com/document/62914) 。同一内容同时走「群聊」和「频道」两条通道，各响应一次会导致重复回答。
