## 背景说明

为提升企业数据安全，2026年9月23日起，企业微信将对获客助手组件可获取的获客转化数据启用「定期授权」机制：
- 获客转化数据：即广告投放时的转化数据，包括客户发起好友申请、客户添加成功、客户首次/多次发消息等。


启用定期授权后，企业管理员单次授权上述数据的有效期为 90 天，到期需重新授权方可继续调用接口获取数据。

说明：2026年9月23日之前已发布到现网的获客助手组件，不受「定期授权」机制的影响，可继续接收获客转化数据的回调，暂不受影响。

## 定期授权机制介绍

### 1. 首次授权

组件接入过程中，企业可对获客转化数据进行开启授权或关闭授权。开启后，你可获得授权在你的场景中的获客转化数据。
![enter image description here](https://wework.qpic.cn/wwpic3az/655034_sugpqS_kT0avFly_1790171100/0)

### 2. 有效期

授权完成后 90 天有效，到期后将无法通过接口继续返回数据，必须由企业管理员重新授权。

### 3. 到期续期提醒
企业微信将在数据权限到期前 7 天/3 天/1 天和到期当天，通过应用消息向管理员推送消息提醒，管理员点击消息即可重新授权。授权后，有效期从授权日起重新起算 90 天。
![enter image description here](https://wework.qpic.cn/wwpic3az/31098_jajcbXUAQ0SjN8o_1790171116/0)

在到期前7天、权限到期和企业主动取消权限时，企业微信也将通过[回调通知](#61637)，告知服务商 。

### 4. 管理入口

企业管理员可在「企业微信管理后台 - 获客助手 -授权接入获客助手」中管理获客转化数据的授权。
![enter image description here](https://wework.qpic.cn/wwpic3az/413832_Gnu28sEZSISEc_d_1790171305/0)

### 5. 查询数据授权

企业微信提供了[获取应用权限详情接口](#48334) ，可查询企业是否授权、授权有效期、内容等，授权内容等，服务商可按需查询。

如企业初次授权之后，服务商可通过此接口查询企业是否授权了获客转化数据权限。

### 5. 引导数据授权

服务商可对未授权获客助手转化数据的企业进行引导授权。可使用跳转到 企业微信管理后台 - 授权权限页面的链接，引导企业进入授权页面。

企业微信管理后台 - 授权权限页面拼接示例: 
https://work.weixin.qq.com/wework_admin/frame#/app/comp/permission?id={SuiteID}

## 授权到期影响

获客转化数据授权到期后，服务商无法通过 API 获取相关数据，影响的 API 范围如下：

|名称 |类型 |表现 |
|:--|
|微信客户打开获客链接 |回调 |不会收到回调|
|发起好友请求事件 |回调 |不会收到回调|
|添加成功事件 |回调 |不会收到回调|
|成员首次收消息事件 |回调 |不会收到回调|
|成员多次收消息事件 |回调 |不会收到回调|
|客户删除成员事件 |回调 |不会收到回调|
|获取获客链接使用成员接受消息数据|API接口|调用返回48002|
